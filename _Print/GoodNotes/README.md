# GoodNotes дэвтэр

Цаасан дэвтэртэй аль болох адилхан: **1-р хуудас нь жинхэнэ нүүр**, дараа нь **60 хуудас цаас** ирмэгээс ирмэг хүртэл. Толгой, дугаар, дүрс зэрэг нэмэлт зүйл байхгүй. Тор эсвэл хоосон хуудас нь жинхэнэ дэвтэр бүрийн үзүүлэлтийг дагасан.

| Дэвтэр | Нүүр | Хэмжээ | Хуудас |
| --- | --- | --- | --- |
| Унших · Reading log | шар баавгай (таны зураг) | 88 × 125 | 3 мм тор |
| Хэрэгжүүлэх · Practice log | ягаан савлуур (таны зураг) | 88 × 125 | 3 мм тор |
| Сэтгэх · Thinking | Meow (таны зураг) | 80 × 123 | 2.85 мм тор |
| Sport im Haus | хар (дэлгүүрийн зураг, нөхөж засварласан) | 88 × 125 | 3 мм тор |
| Bloom | саарал (дэлгүүрийн зураг) | 88 × 125 | 4 мм тор |
| Cherry | улаан (дэлгүүрийн зураг) | 88 × 125 | 4 мм тор |
| Lucky | ногоон (дэлгүүрийн зураг) | 88 × 125 | **хоосон** |
| Travel Bag | цэнхэр (дэлгүүрийн зураг) | 88 × 125 | **хоосон** |
| B5 | нүүргүй | 176 × 250 | 5 мм тор |

- **Цаас:** ойроос харахад ширхэглэг, бүдэг товгор гадаргуутай. Тор нь цул зураас биш, жижиг хэвлэмэл тэмдэгтүүдийн эгнээ. 88 × 125 нь 720 dpi, B5 нь 356 dpi (`make_paper.py`).
- **Нэг хуудастай загварууд** (`template-*.pdf`): GoodNotes-д загвар болгон оруулж, шинэ хуудас нэмэхэд ашиглана.
- **Дэлгүүрийн зургаас авсан нүүрүүд** анхны зураг нь жижиг (~275 px өргөн) учраас таны өөрийн зургаас гаргасан нүүрээс бүдэг. Жинхэнэ дэвтрээ шулуун, гэрэлтэй газар зураад илгээвэл тодорхой хувилбараар сольж болно.

## Анхаар: git-д ордоггүй файлууд

`cover-photos/`, `notebooks/`, `paper-*.jpg`, `template-*.pdf` нь `.gitignore`-д байгаа. Нүүрүүд нь Benstore, ESAER брэндийн дизайн учраас **зөвхөн хувийн хэрэгцээнд** зориулсан. Цаас болон загварууд нь том файл бөгөөд скриптээр дахин үүсгэж болно.

```
python3 _Print/make_paper.py      # цаасны зургууд (numpy, scipy, Pillow), ~1 минут
python3 _Print/make_goodnotes.py  # дэвтэр ба загварууд
```

## GoodNotes-д оруулах

1. PDF-ээ iPad-ийн **Files** руу хадгал → GoodNotes Library → **New → Import**.
2. Шинэ хуудас нэмэх: **Manage Notebook Templates → Paper → Import** → тохирох `template-…pdf`. Эсвэл байгаа хуудсаа **Duplicate** хий.
3. Жижиг хуудсан дээр үзгийн хамгийн нарийн зузааныг сонго.
