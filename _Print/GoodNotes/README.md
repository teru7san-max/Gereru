# GoodNotes дэвтэр

Цаасан дэвтэртэйгээ яг адилхан: **1-р хуудас нь жинхэнэ нүүр** (дэвтрийнхээ зургийг тэгшилж тайрсан), дараа нь **60 хуудас дөрвөлжин тор**, ирмэгээс ирмэг хүртэл. Толгой, дугаар, дүрс гэх мэт нэмэлт зүйл байхгүй.

| Дэвтэр | Нүүр | Хэмжээ |
| --- | --- | --- |
| Унших · Reading log | шар, баавгай (NAVAL) | 88 × 125 мм |
| Хэрэгжүүлэх · Practice log | ягаан, савлуур дээрх охин (LANGUAGE) | 88 × 125 мм |
| Сэтгэх · Thinking | Meow муур | 80 × 123 мм (жинхэнэ дэвтрийн хэмжээ) |

- Торны алхам **2.85 мм**, өнгө нь жинхэнэ хуудасны зурагнаас хэмжсэн.
- `grid-88x125.pdf`, `grid-80x123.pdf`: нэг хуудастай тор. GoodNotes-д загвар болгон оруулж, шинэ хуудас нэмэхэд ашиглана.
- `summaries/`: судалгааны 88 × 125 хураангуй.

## Анхаар: нүүрний зураг git-д ордоггүй

`cover-photos/` болон `notebooks/` нь `.gitignore`-д байгаа. Нүүр нь худалдааны брэндийн дизайнтай (Benstore, ESAER) тул **зөвхөн хувийн хэрэгцээнд** зориулж, repo руу оруулдаггүй. Дахин үүсгэхдээ `cover-photos/` дотор `yellow-bear.jpg`, `pink-swing.jpg`, `meow-cat.jpg` байх хэрэгтэй.

```
python3 _Print/make_goodnotes.py
```

## GoodNotes-д оруулах

1. PDF-ээ iPad-ийн **Files** руу хадгал → GoodNotes Library → **New → Import**.
2. Шинэ хуудас нэмэх: **Manage Notebook Templates → Paper → Import** → `grid-88x125.pdf` (эсвэл `grid-80x123.pdf`). Эсвэл байгаа хуудсаа **Duplicate** хий.
3. Хуудас жижиг тул үзгийн хамгийн нарийн зузааныг сонго.
