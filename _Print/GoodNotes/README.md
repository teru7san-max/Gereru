# GoodNotes дэвтэр (88 × 125 мм)

Цаасан дэвтэртэйгээ яг ижил хэмжээтэй дижитал дэвтэр: 30 хуудас / 60 тал, нүүр, агуулга, ар нүүртэй.

## Файлууд

| Хавтас | Юу байгаа |
| --- | --- |
| `notebooks/` | Бэлэн дэвтэр: нүүр → Агуулга → (заавар) → 60 хуудас → ар нүүр |
| `templates/` | Нэг хуудастай загварууд: `reading`, `practice`, `dot`, `lined`, `grid`, `blank` |
| `summaries/` | Судалгааны 88 × 125 хураангуй (жишээ нь: Handwriting vs typing · Ihara 2021) |
| `covers/` | Нүүрнүүд: нэг хуудастай PDF (GoodNotes-ийн Cover-т), PNG, бүгдийг нь багтаасан `covers.pdf` |

| Дэвтэр | Нүүр | Хуудас |
| --- | --- | --- |
| **Унших · Reading log** | шар, ретро, ном уншиж буй баавгай | Унших бичлэг (хуудсанд 2) + тэмдэг, номын товчлолын хуудас |
| **Хэрэгжүүлэх · Practice log** | ягаан, ретро, pixel охин | Хэрэгжүүлэх загвар (хуудсанд 1) + заавар хуудас |
| **Сэтгэх · Thinking** | цөцгий/хар, "?" бодолтой муур | Dot grid |

Нүүрний дээд хэсэгт хоосон зай үлдээсэн. Цаасан дэвтэр дээрээ бичдэг шигээ "LANGUAGE", "NAVAL" гэх мэт нэрээ GoodNotes дээр гараараа бичиж болно.

## Холбоос (link)

- **Агуулга** хуудсан дээрх 1–60 дугаарын аль нэгийг дарвал тэр хуудас руу шууд очно.
- Хуудас бүрийн баруун дээд буланд байгаа **⌂ байшин** дүрсийг дарвал Агуулга руу буцна. GoodNotes-д "буцах" товч байхгүй тул энэ л буцах арга.
- **Sidebar → Outline** хэсэгт Нүүр, Агуулга, Хуудас 1–10, 11–20 … гэсэн хэсгүүд харагдана.

Линк хамгийн найдвартай ажиллах арга: **Read-only Mode** (зураастай харандааны дүрс) асаагаад дарах. Засах горимд хуруугаар дарвал ажиллаж магадгүй ч Apple Pencil-ээр дарвал зураас болох нь элбэг.

## Оруулах (import)

1. PDF-ээ iPad-ийн **Files** руу хадгал.
2. GoodNotes Library → **New → Import** → файлаа сонго. Эсвэл Files-ээс **Share → GoodNotes**.
3. Хуудас хэлбэр, хэмжээ зөв харагдаж байгааг шалга. Жижиг хуудас дэлгэцийн өргөнд томорч харагдана.

## Загвар нэмэх (шинэ хуудас)

1. Library → GoodNotes цэс → **Manage Notebook Templates → Paper** → бүлэг үүсгэх → **Import → From Files**.
2. `templates/` доторх PDF-үүдийг нэг нэгээр нь оруул. Хэмжээний ангилал (жишээ нь portrait) зөвхөн эрэмбэлэхэд хэрэглэгддэг, хуудсыг томруулж жижигрүүлдэггүй.
3. Шинэ хуудас нэмэхдээ эдгээр 88 × 125 загвараа сонго, эсвэл байгаа хуудсаа **Duplicate** хий. GoodNotes-ийн өөрийн загварууд өөр хэмжээтэй орж ирдэг тул тэднийг бүү ашигла.

## Нүүр солих

- Manage Notebook Templates → **Cover → Import** → `covers/…· cover.pdf`.
- Хэрэглэх: 1-р хуудас → **More (…) → Change Template → Cover** → сонгох → Apply.
- Анхаар: Change Template нь тэр хуудсыг солино. Тиймээс тэр хуудсан дээрх линк алга болж магадгүй. Нүүр дээр линк байхгүй тул энэ дэвтрүүдэд асуудалгүй.

## Зөвлөмж

- **Үзгийн хамгийн нарийн зузааныг сонго.** Хуудас жижиг тул зураас A4 дээрхээс бүдүүн харагдана.
- Нөөцлөхдөө **Export → PDF → "Editable"** сонго. "Flattened" нь линк, outline-ийг устгадаг.

## Эхний удаа iPad дээр шалгах зүйлс

Эдгээрийг судалгаагаар бүрэн баталж чадаагүй тул өөрөө нэг шалгаарай:

- [ ] Хуудас 88 × 125 харьцаатай харагдаж байна
- [ ] Read-only Mode дээр Агуулгын дугаар, ⌂ линк ажиллаж байна
- [ ] Outline харагдаж байна
- [ ] Монгол үсэг (ө, ү) зөв харагдаж байна, хайлтаар олдож байна
- [ ] Хуудас **зөөх, duplicate хийх** үед линк ажилласаар байна
- [ ] Хуудас **устгахад** тэр хуудас руу заасан линк ажиллахаа больж байгаа эсэх

## Дахин үүсгэх

```
python3 _Print/make_goodnotes.py
```

Нүүрний өнгө, хуудасны төрөл, хуудасны тоог `NOTEBOOKS`, `PAGES` дотроос өөрчилж болно.
